## 3. Migration Status Classes

```text
Preserved = concept survives substantially intact inside a new canonical document.
Compressed = concept survives in reduced, cleaner, consolidated form.
Mutated = concept survives but has changed meaning, hierarchy, or role.
Deferred = concept remains valuable but is not expanded in the current compressed project set.
Retired = concept or framing is superseded by a cleaner canonical expression.
Archived = old document should remain available for lineage, but no longer be active project memory.
```
