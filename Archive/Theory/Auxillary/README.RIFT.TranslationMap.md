# README.RIFT.TranslationMap.md

# RIFT Translation Map

## Status

   status: translation scaffold / research bridge / anti-reinvention map

   This document maps Recursive Identity Field Theory (RIFT) and DME V2 concepts onto established domains, methods, and vocabularies.

   It exists to prevent RIFT from reinventing existing mathematics, systems theory, signal processing, neuroscience, machine learning, control theory, graph theory, and philosophy under new names.

   It also exists to prevent premature equivalence.

   A mapping is not an identity claim.

## 1. Purpose

   RIFT / DME has developed an internal vocabulary around:

      attentional continuum
      distinction geometry
      runtime manifold
      phase operators
      admissibility
      proof ecology
      governance
      projection
      retention
      agency
      ledger causality
      feedback ecology

   Many of these concepts overlap with established domains.

      This document answers:

      What existing fields already study pieces of RIFT, what tools should we borrow, where do the analogies break, and what terms should we adopt or avoid?

   This document is not a literature review.

   It is a translation map.

   A future research-context document should expand this with citations, papers, libraries, and technical references.

## 2. Translation Law

   RIFT terms should be translated into established language whenever possible.

   Use RIFT-native terms only when:

   1. no existing term preserves the boundary clearly
   2. the RIFT term names a specific integration across domains
   3. the term prevents semantic collapse
   4. the term preserves an implementation contract

   Avoid mystical inflation.

   Avoid pretending analogies are proofs.

   Avoid replacing established math with poetic synonyms.

   Core law:

   Translate before inventing.
   Differentiate before claiming novelty.
   Preserve boundaries before compressing.

## 3. Core RIFT / DME Compression

   DME V2 is currently implementation-facing as a distinction-first, admissibility-bound, proof-governed runtime for converting source-native emissions into structural distinctions, active runtime states, relation/topology candidates, proof results, governance decisions, and controlled projection / retention / agency feedback.

   RIFT Core Continuum reframes that architecture around a single active substrate:

      Ω(t) = Attentional Runtime Continuum

   Ω is a recursively updated information-energy-attention geometry over distinguishable structure. It includes active Distinction-States, state vectors, local frames, field differentials, interference traces, relation/topology candidates, behavioral bifurcations, uncertainty, attention-energy allocation, and lineage refs.

   The internal RIFT compression:

      DME is a unified attentional continuum whose local runtime geometry self-organizes structure,
      while phase operators lawfully transition that structure through derived coordinate regimes
      under conservation, admissibility, proof, governance, projection, retention, agency, and causal record.

   The translation target:

      RIFT ≈ dynamical systems + information geometry + typed hypergraph causality
            + signal transduction + control theory + proof/stress testing
            + projection/access boundaries + memory lifecycle + agent governance

   But RIFT is not identical to any one of these.
