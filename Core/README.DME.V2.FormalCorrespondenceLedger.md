## 2. Admission Discipline

```text
1. Fetch the primary definition.
   Use textbook, nLab, paper, or other citable source.
   Do not work from model memory of the mathematics.

2. Treat the fetched definition as source text with provenance.

3. Map definition clauses to DME components explicitly.

4. Give every clause a DME counterpart or a declared gap.

5. Hunt counterexamples, not confirmations.

6. Assign status.

7. When in doubt: analogical, never admitted.
```

Core law:

```text
Admit against definitions.

Theorem transfer is a separate, higher gate.
```

### Presheaf Clause Mapping

clause 1 - index category C

DME counterpart: scale bands as objects; declared InterScaleTranslationPaths as morphisms (CLAIM-BL-0093 implies morphisms exist ONLY where paths are declared - C is the category GENERATED by declared paths, not the full scale poset).

status: PARTIAL - see GAP-1.

clause 2 - assignment F(U) per object

DME counterpart: envelope-satisfaction assignments at band U (identity_invariants_by_scale; CLAIM-DEF-0132).

status: MAPS.

clause 3 - restriction map per morphism

DME counterpart: InterScaleTranslationPath (CLAIM-DEF-0141). Lossy translation is not an obstruction: set-valued restriction maps need not be injective (CLAIM-NC-0553 is compatible).

status: MAPS, conditional on clause 1.

clause 4 - functoriality (composition and identities preserved)

DME counterpart: NONE. Doctrine never declares the composite of two translation paths, nor identity translations.

status: UNKNOWN pending GAP-1.

### Sheaf Clause Mapping

DME counterpart: decomposition of a scope into finer-band constituents (document into sections, sentence into spans). Intuitive but UNDECLARED.

DME counterpart: nowhere asserted; possibly undesired.

status: UNDETERMINED - see GAP-3.

### Counterexample Attempts

CE-1 (functoriality, CONSTRUCTIBLE FROM DOCTRINE AS WRITTEN):

Declare path P1: token->sentence (paraphrase; loses wording) and P2: sentence->paragraph (compression; loses order). Doctrine provides no composite token->paragraph path and no law relating the two-step traversal to any direct path. Functoriality cannot be evaluated.

CONCLUSION: presheaf not admittable as written; fixable by one doctrine addition (see open questions).

CE-2 (separation, PLAUSIBLE):

Two distinct document-scale identity claims whose sentence-level restrictions coincide on every section (global identity underdetermined by local satisfaction). If constructible in the markdown prototype, DME is deliberately NOT separated, and the sheaf target should be abandoned in favor of presheaf-with-declared-non-uniqueness.

NEXT TEST.

### Open Doctrine Questions Raised (NOT auto-patched)

ODQ-1: Translation path composition.

Must composites of declared InterScaleTranslationPaths be declared or derivable? What is the loss-profile accumulation rule? (Required for presheaf admission.)

ODQ-2: Covering doctrine.

What constitutes a complete decomposition of a scope into finer-band constituents? (Required for any sheaf-style claim.)

ODQ-3: Identity uniqueness posture.

Does DME assert that compatible local satisfactions determine a UNIQUE global identity claim, or are multiple admissible global identities a feature? (Determines presheaf vs sheaf ambition.)

### Refinement Gift From the Formalism

Sheaf theory distinguishes three failure modes DME's rupture currently lumps together:

```text
(a) overlap-incompatibility - local sections disagree on overlaps
(b) gluing obstruction - compatible sections fail to assemble
(c) non-uniqueness - multiple valid assemblies exist
```

Candidate rupture subtypes for future FeedbackIntegrationEcology refinement.

Sheafification (the known repair of a presheaf into a sheaf) is a candidate formal home for doctrine-compression operations.
