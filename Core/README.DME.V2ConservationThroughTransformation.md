# 1. Purpose

This document defines Conservation Through Transformation as the master invariant grammar underlying DME.

It is not a regime.

It is not a substrate.

It is not an operator.

It is the conservation principle that explains why the regimes exist and how they relate.

The purpose of DME is not storage.

The purpose of DME is not memory.

The purpose of DME is not classification.

The purpose of DME is to preserve coherent structure across transformation.
