## 3. Core Architecture Terms

### DME

```text
DME = Dynamical Memory Engine.
```

DME is a configuration-attention architecture for converting source-supported differences into accountable distinction topology, runtime activation, projection, decision, consequence, feedback, provenance, retention, proof, authority, and reference.

Compressed:

```text
DME = accountable distinction recursion across source, attention, decision, memory, and consequence.
```

---

### RIFT

```text
RIFT = Recursive Invariance / Field Theory layer.
```

RIFT names the deeper theoretical framing around invariance, field dynamics, operators, conservation, and topology that was compressed into DME V2.

Current posture:

```text
RIFT concepts are preserved inside DME V2 theory, operator grammar, distinction ecology, and provenance conservation.
```

---

```text
Configuration-Attention Continuum =
```
