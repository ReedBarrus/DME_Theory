## 1. Purpose

This document indexes the `Agentic_Reasoning` folder.

`Agentic_Reasoning` contains protocols for how assistants, agents, humans, and tool-mediated workflows should reason, remember, compress, constrain, collaborate, and maintain context.

It is adjacent to DME Theory, but it is not the same layer.

```text
DME Theory = architecture of accountable distinction recursion.

Agentic Reasoning = protocols for reasoning with architecture, memory, semantic constraint,
context, collaboration, and agent behavior.
```

The folder exists to externalize reusable reasoning protocols without bloating the core DME architecture chain.

---

## 2. Boundary Law

```text
Agentic_Reasoning governs reasoning behavior.
DME architecture governs system structure.
```

Agentic Reasoning protocols may guide:

```text
how concepts are admitted
how memory is externalized
how definitions are constrained
how assistants collaborate
how agents avoid stale context
how reasoning summaries are produced
how contradictions are surfaced
how archive lineage is handled
```

They should not redefine:

```text
the four substrates
the root regime hierarchy
the operator grammar
the distinction ecology
the agency ecology
the decision/consequence ecology
the DME implementation substrate model
```

Core law:

```text
Agentic Reasoning supports DME work.
It does not replace DME doctrine.
```
