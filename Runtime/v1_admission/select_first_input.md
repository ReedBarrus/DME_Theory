# Select First Input

Choose the first non-self input only after maintainer review of scope.

Selection criteria:

```text
small
public or user-provided
non-DME
stable enough to hash
low-stake
short enough for human review
contains claims/definitions/boundaries
not medical/legal/financial advice
not private/confidential
```

Possible first input classes:

- a public technical README
- a short open-source project design doc
- a public governance/sensemaking essay
- a user-written external project note
- a small policy/spec excerpt

Do not choose the input yet unless the maintainer has supplied one.
