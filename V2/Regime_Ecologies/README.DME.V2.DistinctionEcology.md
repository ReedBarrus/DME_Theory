## 1. Purpose

This document defines the Distinction Ecology of DME V2.

Distinction Ecology is the root regime ecology of DME.

It explains how source-supported differences become bounded, provenanced, attention-eligible, relational, projectable, retainable, proof-testable, decision-relevant, consequential, and releasable.

This document defines how DME converts:

```text
signal topology
→ structural topology
→ distinction topology
→ runtime topology
→ projection / ledger / decision topology
```

It does not define a formal schema.

It defines the conceptual lifecycle, objects, pressures, and non-collapse laws that later schemas must preserve.

---

## 2. Core Thesis

```text
Distinction is the core unit of configuration-attention topology.
```

A distinction is not merely a noticed difference.

```text
A distinction is a bounded, supported difference in configuration space that can receive attention,
enter relation, become projected, influence decisions, be retained, be proof-tested,
and participate in consequence.
```

Distinction Ecology is the geometry of how differences become accountable units of attention, relation, memory, proof, decision, and consequence.

Compressed:

```text
Difference becomes distinction only when bounded, supported, scoped, lensed,
provenanced, and eligible for attention.
```

Final root law:

```text
All DME regimes operate over distinction dynamics.
```

## 4. Distinction Is Not Difference

A difference is raw contrast.

A distinction is supported contrast under scope.

```text
difference + support + scope + lens + provenance + attention eligibility
→ distinction candidate
```

Then:

```text
distinction candidate + structural admissibility
→ DistinctionRegion
```

Then:

```text
DistinctionRegion + runtime activation
→ Distinction-State
```

Then:

```text
Distinction-States + relation + recurrence + pressure
→ DistinctionTopology
```

### Non-Claims

```text
difference ≠ distinction
raw contrast ≠ supported difference
detected feature ≠ distinction
salient difference ≠ valid distinction
recurring difference ≠ proven distinction
```

## 5. Staged Distinction Geometry

Distinction is staged geometry.

A distinction does not appear all at once.

It matures through differential evidence, bounded support, admission, activation, relation, projection, retention, proof, decision relevance, consequence feedback, and release.

Canonical staged lifecycle:

```text
RawDifference
→ DifferentialEvidence
→ StructuralSignature
→ DistinctionEnvelope
→ DistinctionEvidencePacket
→ StructuralAdmissibility
→ DistinctionRegion
→ RuntimeActivationCandidate
→ Distinction-State
→ RelationCandidate
→ DistinctionTopology
→ Projection / Retention / Proof / Decision / Release Route
```

Each stage has different status, geometry, provenance posture, and non-claims.

## 8. Structural Admission as Dual Decomposition

Structural admission decomposes source-native signal into two coupled fields:

```text
Provenance topology
Distinction topology
```

More precisely:

```text
Structural admission maps source-native configuration into:

1. Provenance topology
   transition history, lineage, lens, loss, operator path, reconstruction limits

2. Distinction topology
   bounded supported differences eligible for attention, relation, projection,
   retention, proof, decision, or release
```

The two are inseparable but not identical.

```text
Provenance topology conserves where/how.
Distinction topology organizes what-difference.
```

This means source signals do not become distinctions directly.

They first become structurally transformed, provenanced, and compared across basis.

## 15. Attention and Salience Gating

Attention is finite runtime budget over distinction topology.

Salience may request activation.

Support and admissibility determine activation.

```text
Salience may request activation.
Support and admissibility determine activation.
```

A distinction should not become active merely because it is salient.

Runtime activation should require:

```text
current structural support
provenance integrity
current window/frame relevance
attention budget
admissibility
risk / consequence tier
projection contamination check
retention contamination check
```

### Salience Gating Law

```text
Runtime gating prevents projection or attention from over-stabilizing weak distinctions.
```

### Attention Allocation Law

```text
Attention allocation should be proportional to active support, relevance, uncertainty,
risk, and provenance integrity, not salience alone.
```

Uncertainty may increase proof attention.

Uncertainty may not increase authority.

```text
uncertainty may increase proof budget
uncertainty may not increase authority
```

How consistently the distinction appears across transforms, lenses, or coordinate bases.

How coherently the distinction relates across windows without pretending identity.

How many meaningful relation candidates connect it to other distinctions.

How strongly the distinction can affect branch topology.

### Authority Ceiling

How much consequence the distinction may influence.
