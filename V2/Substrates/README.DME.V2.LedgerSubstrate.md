## 1. Purpose

This document defines the Ledger Substrate of DME V2.

The Ledger Substrate is the bounded provenance hypergraph where accountable transitions become reconstructable causal history.

It records and folds:

```text
source admissions
operator spans
provenance envelopes
structural distinctions
runtime activations
projection handles
decision branches
execution receipts
consequence signatures
feedback records
integration results
retention changes
proof traces
authority deltas
reference states
canon posture
revocation / archive / quarantine events
```

The Ledger Substrate is not an infinite event log.

It is not a truth machine.

It is not memory by itself.

It is the conserved causal-provenance topology that supports reconstruction, retention, proof, authority, reference, and future runtime curvature.

## 8. Receipt Trigger Conditions

A receipt is required when movement:

```text
crosses substrate boundary
changes retention state
creates or updates a projection handle
creates a DistinctionRegion
accepts runtime activation
forms a decision branch
permits execution
emits consequence
receives feedback
integrates consequence-feedback
introduces declared loss
runs a proof/load test
changes access
changes authority
creates reference/canon posture
archives, revokes, or quarantines an object
```

A receipt is not required for every micro-operation.

Low-level movements may be aggregated into OperatorSpans.

Example:

```text
Structural admission span:
Expose + Bound + Differentiate + Transform + Relate
→ one StructuralAdmissionReceipt
```

Core law:

```text
Receipts conserve accountability at meaningful boundaries, not every micro-movement.
```

## 15. Resolution and Loss Boundaries

A ledger record or fold must declare what can and cannot be reconstructed.

### ResolutionBoundary

```text
ResolutionBoundary =
declared limit of detail recoverable from a record, fold, projection, archive, or reconstruction path.
```

### LossBoundary

```text
LossBoundary =
declared boundary beyond which omitted axes, uncertainty, or transformation loss prevent stronger claims.
```

Examples:

